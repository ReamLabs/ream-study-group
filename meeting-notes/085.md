# Ream Meeting #85 Recap

## Overview

This week's topics spanned ethlambda interop and the encoding/API fixes behind it, devnet hosting and scaling constraints (proof size, server availability, and a Shadow-based validator-scaling push), leanVM 0.9 image adoption, new gossip metrics and a slot-index fix, and a plan to stand up a large real devnet.

## Development Progress

### Interop & Devnets

- **ethlambda interop**: [Shariq] Fixed the encoding scheme to match the latest API, so ream can now interop with ethlambda, and reached out to Mega to get ream included in the EF-hosted interop devnets. A local three-validator devnet showed a ~17-slot finalization delay, driven by ~12 GB proofs on this branch — about as far as his hardware can push it. Also merged Barnabas's PR fixing build issues.
- **Devnet hosting**: [Shariq] Hetzner no longer has availability for the cheap servers previously used, so the options are to lean on ethlambda running the official EF devnets on larger nodes, or find a different hosting solution.
- **leanVM 0.9 image**: [Kolby] Reviewed around six PRs (about half on sync/network-lag handling, one an EF-authored data-availability client), and looked into how ethlambda runs its devnets — it publishes both an old-leanVM image and the newest 0.9, and runs devnets on 0.9 for its performance improvements and cleaner API; opened a PR to adopt it.

### Testing & Simulation

- **Shadow validator scaling**: [Derek] Pushed Shadow toward larger scale to gauge public-instance capacity, running validators inside a node — 4 nodes with 4 validators each was ~2.4x runtime, 64 validators was ~8x, but a 512-validator overnight run failed, likely a keygen bottleneck from generating so many keys; plans a key cache/backup so it doesn't recur.
- **Gossip metrics & slot-index fix**: [Kayden] Added six new gossip-arrival-timing metrics, pushed a fix keeping the slot index canonical across side-branch imports and reorgs, reviewed the devnet-5 lean image integration (built by Shariq and Kolby over the last month), and started running the devnet to test it.

### Large Devnet Planning

- **1000-node devnet**: [Kolby, Shariq] Discussed standing up a large real devnet starting with ream — whether to double the slot interval to 8-second slots (Shariq expects it may be unnecessary now that the expensive type-1 aggregation is removed), and whether to use their own machines in a Tailscale mesh network rather than spend heavily on servers. They will crunch the numbers for a real (non-simulated) devnet.

- **Kolby**: Finish the remaining PR reviews, land the leanVM 0.9 image PR, and size the Tailscale mesh devnet with Shariq.
- **Kayden**: Run the devnet tests for the devnet-5 lean image integration.
- **Derek**: Fix the Shadow 512-validator keygen failure with a key cache and keep scaling the runs up.
